Projeto HTML5

Projeto desenvolvido para estudo e prática de desenvolvimento web fundamental utilizando HTML5 e CSS3.

Sobre o Projeto

O objetivo deste repositório é demonstrar a estrutura de uma página web moderna utilizando elementos semânticos do HTML5, estilização com CSS3 e organização de arquivos de um projeto front-end simples.

Tecnologias Utilizadas

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, layout e formatação visual.

Estrutura de Arquivos

Projeto-HTML5/
├── index.html        # Página principal do projeto
├── css/             # Arquivos de estilo CSS
└── img/             # Imagens e ativos visuais do projeto
