# 🌐 Projeto HTML5

Projeto desenvolvido para o estudo e a prática de desenvolvimento web com **HTML5** e **CSS3**, aplicando uma estrutura semântica e a organização de arquivos de um projeto front-end simples.

## 🎯 Objetivo

Demonstrar a construção de um site de várias páginas usando elementos semânticos do HTML5, estilização com CSS3 e uma estrutura de pastas organizada, servindo como base de estudo para projetos web futuros.

## ✨ Funcionalidades

- Site com várias páginas ligadas por navegação:
  - **Início** (`index.html`): página principal do projeto.
  - **Projetos** (`projetos.html`): página de apresentação dos projetos.
  - **Cadastro** (`cadastro.html`): página com formulário de cadastro.
- Estrutura semântica com elementos do HTML5, que deixa o conteúdo mais claro e acessível.
- Estilização, layout e formatação visual feitos em arquivos CSS separados.
- Organização de imagens, estilos e scripts em pastas próprias.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso no projeto |
|---|---|
| **HTML5** | Estrutura semântica do conteúdo |
| **CSS3** | Estilização, layout e formatação visual |
| **Git e GitHub** | Versionamento e hospedagem do código |

## 📁 Estrutura de arquivos

```text
Projeto-HTML5/
├── index.html      # Página principal
├── projetos.html   # Página de projetos
├── cadastro.html   # Página de cadastro
├── css/            # Arquivos de estilo
├── images/         # Imagens e ativos visuais
├── js/             # Scripts do projeto
└── README.md       # Documentação do projeto
```

## 📚 O que aprendi

- Uso de tags semânticas do HTML5.
- Aplicação de estilos com CSS3 em arquivos separados.
- Organização de um projeto front-end em pastas.
- Uso de Git e GitHub para versionar o código.
